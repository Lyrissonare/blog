# 用「蓝」设计一个博客

打开暗色主题，最先看到的是灰。页面底色落在 `#0e1013`，卡片只亮一级，正文使用带着暖意的 `#e8e6e0`。蓝色留到链接、当前页、按钮和指针经过的地方。Cyanote 的名字没有改，“Render ideas in blue.” 也没有改，颜色的分工已经重新排过。

旧版暗色主题把亮色页面压暗，再用更亮的蓝维持辨识度。新版从背景开始安排明暗，让文字、边框和卡片先各自归位，蓝色随后进入。文章标题里的“蓝”因此有了更具体的含义：它负责指引，也负责回应。

## 先让蓝色退后半步

当前色板把暗色主题分成三层。页面是石墨黑，卡片与侧栏略亮，代码块再沉下去。正文与次级文字也分开，眼睛先读到文章，随后才注意到日期和说明。

```css
html[data-theme='dark'] {
  --accent: #2f5f92;
  --accent-2: #74a9dd;
  --accent-3: #aac9e7;
  --accent-soft: #15202b;
  --bg: #0e1013;
  --bg-elev: #14171b;
  --bg-soft: #1a1e23;
  --bg-code: #0a0c0f;
  --text: #e8e6e0;
  --text-2: #a5a8ad;
  --border: #272b32;
}
```

`--accent` 适合按钮填充；`--accent-2` 是钢蓝，出现在链接、当前导航和焦点状态；`--accent-3` 更浅，留给少量高光。三种蓝色各自有岗位，页面无须靠同一种高饱和蓝反复提醒品牌。

卡片边界也由灰色完成。`#272b32` 的边框勾住轮廓，黑色投影把卡片从背景上托起来，内侧一道 3.5% 透明度的白色高光留住纸面的厚度。页标题在暗色下取消渐变，恢复成纯色文字。视觉层级来自明度差，阅读时会更省力。

亮色主题仍沿用 `#2563eb`、`#3b82f6`、`#60a5fa` 这组更清澈的蓝。两套主题共享结构，各自拥有合适的光照。

主题切换也尊重读者所在的环境。没有手动选择时，站点跟随浏览器或操作系统，系统换色会同步传到页面。主题按钮角上的小点表示正在自动跟随；点击之后，选择才会存进本地。Shift 加点击或右键可以回到自动状态。色板因此有了时间维度，清晨和深夜打开同一个地址，看到的是各自合适的光照。

## 标签只留一道钢蓝色边

标签曾用浅蓝底把整颗胶囊填满。暗色版现在抽掉底色，只保留文字与描边。

```css
html[data-theme='dark'] {
  --tag-text: #6f9fc4;
  --tag-bg: transparent;
  --tag-border: color-mix(in srgb, #6f9fc4 58%, transparent);
  --tag-hover-text: #0b1219;
  --tag-hover-bg: #a8c8e0;
}
```

透明底让标签与卡片共享同一层灰，58% 的描边足以交代点击范围。指针悬停时，胶囊填成浅蓝，文字转为深色。静止与操作拥有两种清楚的状态，标签云也不再挤满蓝色块。

同样的取舍延伸到其他组件。导航下划线、章节标题侧线和卡片左侧提示条都改用单色钢蓝，省去重复的渐变。置顶标记使用红色细描边，功能色只出现在它该出现的位置。蓝色因节制而更容易辨认。

## 星光会跟着指针醒来

石墨底上铺着颗粒与十字星。颗粒打破纯色背景的平滑，两种尺寸的星光错落在上方，径向遮罩让它们向下淡出。页面滚动到长文中段，装饰已经退场，正文仍占据完整的注意力。

指针移动会唤起另一层星光。前景光晕以 `0.16` 的插值系数跟随，背后的星光亮层使用 `0.085`，慢半拍到达。两层光错开很短的一段距离，静止的背景由此产生纵深。星光只在本该暗下去的地方亮起来，文字下方始终保留干净的卡片。

这套效果只服务于暗色主题和精细指针设备。触屏会关闭指针辉光与星光背板，开屏播放时也暂停跟随。两层光抵达目标后，动画帧会停止请求；下次移动指针，它们再醒来。氛围依赖光的出现与消退，不需要持续运动的噪声填满屏幕。

首页文章列表末尾也使用了这种“出现之后消退”的思路。文章数量超过首页展示额度时，下一张卡片的下缘会被撕开，带切面的碎片向下散落，“查看全部文章”的按钮浮在空出来的位置。列表有了尽头，阅读入口仍留在原处。

## 一枚标志，把前后串起来

页头原来的 `C` 字母换成了一张蓝色便签。纸面右侧留着弧形缺口，钢笔斜放在上方，手写体的 `note` 落在中央。图标同时承担“书写”与“记录”两件小事，和博客的用途直接相连。

旁边的 `Cyanote` 改用 Mrs Saint Delafield 字体。字标有手写笔画，导航和正文继续使用无衬线字体，花体只停在品牌区域。字体文件随站点本地提供，并在页面打开时预载。

同一枚标志还进入 favicon 与开屏。页头使用 40px 图标，开屏放大到 72px，明暗主题各自使用对应资源。水滴落下后，标志与字标浮现；鱼眼收镜时，它们先退出，真实页面随后显露。首页副标题和页脚的 “Render ideas in blue.” 则把这句英文留在两个首尾位置，互不抢话。

## 文章页把注意力还给正文

文章页的元信息重新排过。作者名留在标题下方，首页卡片和文章列表不再重复它；阅读次数离开正文页，日期、分类与标签使用 12px 字号和更窄的间距。信息仍然齐全，标题与正文之间少了几样争夺目光的数字。

正文的阅读尺度保持不变，16px 字号配合 1.9 倍行高。二级标题保留蓝色左边线，目录跟随滚动标记当前位置。点击目录时，标题会停在吸顶页头下方，不会被导航遮住。屏幕窄到 900px 以内，目录与侧栏回到正常文档流，文章卡片缩小内边距，长文在手机上也能顺着一列读完。

代码块换成接近页面底色的 `#0a0c0f`，文字改为灰白，边框也回到灰色。旧文章里亮度较高的蓝色封面会自动降低饱和度与亮度，进入新版暗色页面时不会突然跳出一块刺眼的颜色。

## 未来主义仍在隔壁

未来主义模式继续保留。打开开关，`body.future-mode` 会换上紫色、青色、流动网格与玻璃卡片，文章页和侧栏也进入同一套皮肤。网格以 24 秒一轮漂移，首页光球用 9 秒完成往返，开关状态会保存在本地。它与亮色主题同时开启时，页面会给出切换暗色的入口。

这套皮肤承担的是另一种情绪。两种外观共享同一套导航与文章数据，切换只改变呈现。日常阅读回到石墨、暖白与钢蓝；想看霓虹时，开关仍在原处。指针停下，星光也慢慢停下，蓝色留在链接上，等下一次点击。
