《8102》是Lost in Tianyi的专辑曲。说实话，我认为它呈现的和条条一贯的创作风格并不太一样。当然由于我完全不懂乐理，所以先从歌词角度，浅浅写一下我的感受吧（不是解析！）

```
即使认真对待每时每刻
碾着愿望的车轮仍在转动
```
这两句歌词是电话音。一般来说电话音可能象征一个“遥远”或者说“不真实”的东西。那么放在这里我觉得更像是一个浮在雾中的前提。

```
倒流历史的始终
颠覆盖棺的对错
回到尚且一片空白的宇宙
```
这三句其实是很重的。“盖棺定论”代表一个人彻底入土，不能再在世上有所作为之后，对他的评价也最终完成。那么什么情况下我们会推翻一个盖棺定论的评价？那必然是在观念发生重大转变之后。例如现在提到古人的某某品质，就得加一句时代的局限性，当然也不乏彻底反转的例子。那么代入到歌词中，意思就是未来与现在的观念非常的不同了。

```
每天唠叨却又完全没记住的姓名
被归纳在过去（在过去 在过去）
耳濡目染被迫了解到的繁琐事情
一字一句勾画未来雏形
```
过了一小段间奏（？）之后就是这里。不知道你们看到这几句词可能会联想到什么，我想到的是新闻。新闻画面上不就是充满了每天提及的各种姓名，和各种繁琐的事情，以及会决定未来的节点吗？一位小朋友长大的过程感觉就是这样，上一个阶段熟悉的各种姓名逐渐远去归档，而懵懵懂懂看到的各种新闻实际上是未来生活的“前瞻”。

```
麦田涟漪中掷出的纸飞机
乘着风穿过水泥森林回到我怀里
```
继续接我上面说的，“小朋友长大”的路程，这里想必是不难理解的。“钢铁水泥森林”这个词我不知道第一次爆火可能是什么时候，但至少对我来说是19年之后，看到一首18年的歌里有这个我还是很惊讶的。

```
飞快地改变又改变
更迭再更迭
撕去的日记还是那一页
```
这里的意象开始从具体步入抽象。唯一具体的是“日记”。但什么叫做“撕去的日记还是那一页”？我觉得这里可能代指某些没有变化的感受，或者说“螺旋上升”的话，就是相同的一个扇区。

```
即使认真对待每时每刻
碾着愿望的车轮仍在转动
```
如果说前面是正常的叙事，这里就是“虚拟语气”了。“即使”，那么上面所提到的日记真的到来了么？

```
倒流历史的始终
颠覆盖棺的对错
回到尚且一片空白的宇宙
```
这里和开头是一样的，所以我在这里说点不一样的，来点“暴论”。就是我认为这首歌是有很多故意制造的谐音地方的，倒流历史的「始终」（时钟）可能是其一。车轮，时钟都是旋转的东西，一般大家也都会说“时光倒流”而不是“颠倒始终”。

```
即使将故事打碎按我的想法拼凑
新天气新目的新世纪的人们仍然在说
“大闹一场的狼藉
骇俗到不可思议”
来自8102的恶意就在这里
```
这一段是“明牌”了8102不是一个好的未来。“新年新气象”结果是反着新的，未来的人们变得更加固步自封，面对小洛的举动已经无法理解，将其视为大闹的一段。同时，虚拟语气又来了，“即使”将故事打碎...其中的是非曲直也是难以论说。

```
反复争议却又完全没改观的话题
很快就被忘记（被忘记 被忘记）
前赴后继却在指摘之下没了声息
凝固曾回温的一点一滴
```
前两句真的就是舆论场现状了。或者不如说，正因为反复争议却无法改观，才会被忘在脑后。这儿我其实想说不建议把这两句直接拟合到任何具体的话题上，这种过拟合可能也是固步自封的一种。后两句写的是”千夫所指“对于个人的...不知道怎么说，一人出一粒灰，压到某个人头上就是一座山？这样的感觉。

```
林立楼宇穿梭来去的身影
烙印在清澈眼底深深扎根我生命
```
这两句还挺有画面感的。这里穿梭来去的身影是新世纪却依然固步自封的人们还是和小洛一样的理想主义者呢？我认为是后者。这里结合后面三句会更好：

```
乏味地发生又重演
涂抹再改写
孤身一人沉默的辩解
```
其他同样在奔走的人们，他们的努力被抹去，改写回原本的形状，同样的事情一遍又一遍上演，小洛作为见证者看在眼里，最后只剩她一人面对。同时这里我还要发动谐音论，”辩解“谐音”边界“，一个人沉默的边界在何处？是否能因为沉默而免于指责？我沉默的努力的”上限“又在哪里？

```
即使认真对待每时每刻
碾着愿望的车轮仍在转动
逆转既定的福祸
重置戏剧性因果
苦思冥想后剧本只字未落
```
如果说前面是小洛面对社会的困境，这里就是她本人的困境。把故事打碎从头开始写起，即是重置了所有的因果，那这剧本应该怎么写才好，怎么写才能避免一个新的旧世纪呢？像不像拆解原作故事写同人的你（狗头）。

```
即使将成见抛下按本心所想而活
透过旧规矩旧思绪的囹圄能看到什么
```
于是小洛开始反思：如果我真的抛开一切成见，那从现在的“局限性”出发，我又能写出怎么样的剧本呢？这里有必要提到我们此前说的“古人的时代局限性”，小洛也在反思自己，是否也有这种局限性呢？

```
正面教材的典型
矫枉过正的范例
来自8102的池鱼仰望天际
```
这一段很重要。继续我此前的谐音论，这里的“范例”谐音“藩篱（我第一次听到的确是这么理解的），即打破旧牢笼之后，得到的只是新的围栏，"矫枉过正"建的藩篱。”池鱼“谐音~~赤羽~~“痴语”，即小洛在8102的话语已被视为不被理解的、近乎痴人说梦的话语。
不过，这里按原意解也是很妙的。《世末歌者》中有几句画面感特别强的词，`沉入冰冷的池底 注视着 色彩褪去`，如果是世末歌者里面是“沉鱼”，这里就是尽力观天的池鱼。我们知道在水中存在“斯内尔窗”现象，窗内能直接看到水上的世界，窗外整圈都是"镜子“，这也许可以作为一种局限性的隐喻。
”池鱼“在中国古典文学中也是比较经典的意象了，可以让人联想到“殃及池鱼”的无辜受累，也可以让人想到“池鱼思故渊”的归返愿望。如果结合前面提到的内容，我认为在这里可能更接近：即使身陷局限（并且自知局限），向往本身仍未被消灭。

```
何谓正确
（如果）茶余饭后能够笑谈
```
这里接着前面，如果打破就的牢笼之后只不过是新的围栏，那么什么才能称之为”正确“呢？
这里的“笑谈”的人是谁呢？如果是之后的小洛，那是一句非常不确定的自我安慰。也许将来的某一天我能把当前这些奔走、这些失败都化作笑谈轻轻讲起。但如果是后来的人们，则颇有些那种，站在屏幕外面观看他人的苦难当做笑谈的意味。“你们日后也许只会把这些事当成茶余饭后的谈资，又凭什么只凭一个成败结果，指责此刻仍在奔走的我？”

```
不停呼号奔走为了理想的结果
结果不如人意就再次从头来过
不要再指责从没放弃的我
```
这里有一处急转，最重要的已经不再是结果是否正确，而是一个人有没有权利继续尝试。我所要求的甚至不是赞美，只是不要再因失败而遭受指责。由此，前面的宏大想象落回了非常具体、也非常卑微的愿望：允许我失败，允许我重来，允许我按照自己的本心活一次。“澎湃的孤独感渐渐将她对名利的渴望浇熄，阿绫只剩下谁能够尝试靠近，并问询自己的卑微愿望”，~~真是一对苦命鸳鸯~~

```
此时此刻若是能逃开这水复山重
载着愿望的车轮开始转动
```
这里开始再次“由实转虚”，但这次不是意象变虚，而是整个意境都虚化了。车轮也不再将愿望碾作齑粉，而是成为其的载体。

```
抖落世纪的尘埃
沿途风信子初开
去到距地面六千光年之外
巨大的引力边缘一切都变得缓慢
8102的钟声回到耳畔
```
这是“逃离”的具象画面，和《逃子》中使用焦油焚烧的向日葵田一样也是一片花海。既然现实中一切变化得太快、评价来得太急，那我就去一个连时间都慢下来的地方。

```
世界咫尺处变迁
朝向启程的零点
目力所及处的某一天
你在身边
```
不过，这并不是完全的逃离乃至切割过去（这里的过去实际上是“未来”）。这里（连着上面）的空间波动十分剧烈，个人觉得这种远近交错也许想说，真正需要改变的未必只是外部环境，也还有人看待世界和自身的位置。最终小洛找到的“答案”是什么呢？是「连接」，每一个听众和她的连接。也许，只要不再是独自启程的愿望，就能得到理想的未来呢？

## 写在最后

《8102》这首歌我一直“听不懂”，即便我写了这么一篇拼拼凑凑信口雌黄的文章，也不代表我能有什么理解，~~更何况半夜写完还不检查~~。我曾将这个问题问向群友，群友告诉我他的理解是：这首曲有一点“时间叙诡”，大概就是，无论现在的故事如何跌宕复杂，感情如何炽烈，等到六千年后都不过是一抔黄土，被压缩成历史书上短短的几个模糊字眼，而六千年后的人即便想要与六千年前的故事的感情产生共鸣也已经走投无路，现在之于未来和未来之于现在都是这种相望不相闻的绝望的隔绝状态。

那我们便可以读出另一个不同的结局，6000光年代表6000地球年的“时差”，我能够看见你，甚至感觉你就在身边，却依然无法确认你是否真正听见了我。而“在身边”正是“相望不相闻”的最后一次想象性越界。时间方面则非常新三国：一方面，我似乎仍在经历当下：奔走、呼号、辩解、试图重来；另一方面，这个尚未结束的当下却已经提前进入了历史叙述。换句话说，人还在故事里，故事却已经把他当成了死人；现实还在发生，历史却已经急着替他定义了。但故事和历史都拼凑不出人的心音了。

站在现在回看，条姐在18-20年的创作很多都在强调“初心”（例如Earth Hour，也是难得一见的“锋芒”歌词），而本曲既与初心连接，也和《世末歌者》的现代性危机的命题相通。现代化承诺“新”，以“改变”“更迭”为常态，但旧规矩并没有消失，争议也只是重复。线性的进步时间像车轮一样前进，却未必“载着”所有人的愿望，反而可能从愿望上“碾着”过去。

那么，条姐对《世末歌者》剧情的那一句`或许当世末中的人们愿望也变得简单时，就能从困局中解脱了`，似乎也有了答案。

宿舍熄灯了，还有一些没整理没写完，未完待续...
