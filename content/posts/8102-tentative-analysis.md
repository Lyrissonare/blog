《8102》是Lost in Tianyi的专辑曲。说实话，我认为它呈现的和条条一贯的创作风格并不太一样。当然由于我完全不懂乐理，所以先从歌词角度，浅浅写一下我的感受吧（不是解析！）

```
即使认真对待每时每刻
碾着愿望的车轮仍在转动
```
这两句歌词是电话音。一般来说电话音可能象征一个“遥远”或者说“不真实”的东西。那么放在这里我觉得更像是一个浮在雾中的前提。

```
倒流历史的始终
颠覆盖棺的对错
回到尚且一片空白的宇宙
```
这三句其实是很重的。“盖棺定论”代表一个人彻底入土，不能再在世上有所作为之后，对他的评价也最终完成。那么什么情况下我们会推翻一个盖棺定论的评价？那必然是在观念发生重大转变之后。例如现在提到古人的某某品质，就得加一句时代的局限性，当然也不乏彻底反转的例子。那么代入到歌词中，意思就是未来与现在的观念非常的不同了。

```
每天唠叨却又完全没记住的姓名
被归纳在过去（在过去 在过去）
耳濡目染被迫了解到的繁琐事情
一字一句勾画未来雏形
```
过了一小段间奏（？）之后就是这里。不知道你们看到这几句词可能会联想到什么，我想到的是新闻。新闻画面上不就是充满了每天提及的各种姓名，和各种繁琐的事情，以及会决定未来的节点吗？一位小朋友长大的过程感觉就是这样，上一个阶段熟悉的各种姓名逐渐远去归档，而懵懵懂懂看到的各种新闻实际上是未来生活的“前瞻”。

```
麦田涟漪中掷出的纸飞机
乘着风穿过水泥森林回到我怀里
```
继续接我上面说的，“小朋友长大”的路程，这里想必是不难理解的。“钢铁水泥森林”这个词我不知道第一次爆火可能是什么时候，但至少对我来说是19年之后，看到一首18年的歌里有这个我还是很惊讶的。

```
飞快地改变又改变
更迭再更迭
撕去的日记还是那一页
```
这里的意象开始从具体步入抽象。唯一具体的是“日记”。但什么叫做“撕去的日记还是那一页”？我觉得这里可能代指某些没有变化的感受，或者说“螺旋上升”的话，就是相同的一个扇区。

```
即使认真对待每时每刻
碾着愿望的车轮仍在转动
```
如果说前面是正常的叙事，这里就是“虚拟语气”了。“即使”，那么上面所提到的日记真的到来了么？

```
倒流历史的始终
颠覆盖棺的对错
回到尚且一片空白的宇宙
```
这里和开头是一样的，所以我在这里说点不一样的，来点“暴论”。就是我认为这首歌是有很多故意制造的谐音地方的，倒流历史的「始终」（时钟）可能是其一。车轮，时钟都是旋转的东西，一般大家也都会说“时光倒流”而不是“颠倒始终”。

```
即使将故事打碎按我的想法拼凑
新天气新目的新世纪的人们仍然在说
“大闹一场的狼藉
骇俗到不可思议”
来自8102的恶意就在这里
```
这一段是“明牌”了8102不是一个好的未来。“新年新气象”结果是反着新的，未来的人们变得更加固步自封，面对小洛的举动已经无法理解，将其视为大闹的一段。同时，虚拟语气又来了，“即使”将故事打碎...其中的是非曲直也是难以论说。

```
反复争议却又完全没改观的话题
很快就被忘记（被忘记 被忘记）
前赴后继却在指摘之下没了声息
凝固曾回温的一点一滴
```
前两句真的就是舆论场现状了。或者不如说，正因为反复争议却无法改观，才会被忘在脑后。这儿我其实想说不建议把这两句直接拟合到任何具体的话题上，这种过拟合可能也是固步自封的一种。后两句写的是”千夫所指“对于个人的...不知道怎么说，一人出一粒灰，压到某个人头上就是一座山？这样的感觉。

```
林立楼宇穿梭来去的身影
烙印在清澈眼底深深扎根我生命
```
这两句还挺有画面感的。

宿舍熄灯了，未完待续...
